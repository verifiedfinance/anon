# Anonymous-review notes

The publication export removes machine-local files, clears notebook outputs, and
rejects known personal identifiers and absolute home-directory paths. It cannot
make the existing Git history anonymous. Use a fresh repository and neutral
commit metadata for double-blind review.

Before submission, inspect PDF/SVG metadata, image metadata, notebooks, archive
links, model-provider dashboards, GitHub organization membership, and any DOI or
dataset record that could identify the authors. Replace the provisional
`CITATION.cff` after the review period.
